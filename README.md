🗺️ Raster Footprint Creator

A Python-based GIS automation tool for creating polygon footprints from raster datasets in batch processing mode.

The tool provides a simple desktop interface where users can select an input folder containing raster files, choose an output folder, and automatically generate footprints for the available raster datasets.

🚀 **Key Features**

- 📂 Select input raster folder
- 📁 Select output folder
- 🗺️ Automatically create raster footprints
- ⚡ Batch processing of multiple raster files
- 📊 Real-time processing progress
- 📝 Processing log
- ⏹️ Stop processing
- 🗑️ Clear processing log
- 📂 Open output folder directly from the application
- 🖥️ Simple desktop GIS interface
